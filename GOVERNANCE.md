# Governance

MeTTafy uses lightweight maintainer governance appropriate to an early research project.

## Maintainer

The founding maintainer is **Paul Carver Tiffany III**. The maintainer currently has final responsibility for releases, repository settings, licensing decisions, security response, and merging changes.

## Decision principles

Project decisions should prefer:

1. correctness and reproducibility over novelty claims;
2. interoperability with the MeTTa/Hyperon ecosystem over unnecessary duplication;
3. explicit provenance and attribution over implicit borrowing;
4. small reversible changes over premature framework commitments;
5. evidence-backed semantic classifications over confident guesses;
6. open discussion of uncertainty, limitations, and prior art.

Substantive architectural decisions should be recorded in issues, pull requests, or architecture documentation so the reasoning remains inspectable.

## Contributions and review

Contributors retain authorship of their contributions while licensing accepted contributions under the repository's MIT License. Pull requests should be reviewable, tested where applicable, and explicit about third-party code or ideas they materially depend on.

The maintainer may delegate review or merge authority as the contributor community grows. If the project develops multiple regular maintainers, this document should be revised to describe decision rights, conflict resolution, release authority, and maintainer succession explicitly.

## Independence

MeTTafy is an independent community project. Participation by contributors from an upstream project does not imply endorsement by that upstream organization, and MeTTafy should not present compatible or derivative work as official upstream functionality without explicit authorization.
