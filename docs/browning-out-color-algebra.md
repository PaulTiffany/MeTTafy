# Browning-Out Color Algebra

This note advances Track B of the independent Four Color proof program. It is not the held-out Rocq exemplar and does not import the Four Color conclusion.

## 1. Object of study

Let `G=(V,E)` be a finite planar graph. A coloring assignment is represented by symbolic color states `c(v)` together with indexed edge obligations

```text
O_(u,v) : c(u) != c(v).
```

The obligations are distinct by edge identity even when two endpoints currently carry the same color value. Provenance is therefore retained independently of value reuse.

We distinguish:

- **terminal chromatic classes**: stable, independently discriminable color values that survive the observer/refinement quotient;
- **composite states**: symbolic mixtures whose provenance is retained but whose additional apparent distinctions are not terminally independent;
- **brown**: the canonical composite/residue class produced by amortizing unresolved chromatic provenance without erasing the indexed obligations that generated it.

Brown is not a fifth terminal color.

## 2. Browning-out operator

Let `C` be the symbolic color state space and let `Q` be the terminal quotient. Define an amortization operator

```text
B : C -> C
```

with the following intended laws.

### B1. Obligation preservation

`B` never deletes an indexed edge obligation. If `O_e` exists before amortization, its provenance remains recoverable after amortization.

### B2. Terminal-idempotence

For every terminal class `q in Q`,

```text
B(q) = q.
```

### B3. Composite contraction

If a state contains only distinctions already generated by the same pairwise obligation algebra, repeated amortization does not create a new terminal class:

```text
B^n(x) -> q      for some q in Q,
```

or

```text
B^n(x) -> brown,
```

where `brown` is composite residue rather than a member of `Q`.

### B4. No provenance erasure

`brown` is not zero, grey, cancellation, or forgetting. It records that multiple chromatic histories have been amortized into one composite state while their indexed obligations remain auditable.

This is the sense in which the system *browns out* rather than greys out.

## 3. Relation to Brownian/amortized dynamics

The stochastic analogy is not that colors perform a random walk. The relevant structural correspondence is coarse-graining: many local perturbations may be represented by an effective process after microscopic provenance is amortized. Principia's TTCS already supplies a stochastic symbolic operator over a free-energy landscape, while TTPR supplies deterministic refinement and TTDC terminal collapse.

The proof program therefore uses the following division of labor:

```text
TTCS : explore local symbolic alternatives
TTPR : contract/refine while preserving obligations
TTDC : commit only when a terminal class is stable
TTIE : re-expand retained residue when commitment is not yet justified
```

Browning-out is the observable signature of repeated refinement when apparent extra chromatic distinctions are composite rather than terminally independent.

## 4. Algebraic proof target

The central statement is not `quadratic => four`. That implication is false in general.

The target is instead:

### NoStableFifthClass — Browning Form

For a planar pairwise adjacency constraint system represented in the Principia quadratic symbolic calculus, every putative fifth terminal chromatic class `x5` satisfies exactly one of:

```text
collapse(x5) = qi      for some existing terminal class qi,
```

or

```text
collapse(x5) = brown,
```

where `brown` is a composite residue whose indexed obligations remain recoverable but which contributes no additional terminal discriminability.

Equivalently,

```text
rank_disc(C / ~_amort) <= 4.
```

The novelty claim lives entirely in proving this bound from planarity + the declared symbolic dynamics, not from the classical Four Color theorem.

## 5. Exemplar handles from Principia

The proof is attacked by multiple independent symbolic handles rather than one analogy.

### E1. Minimal Quadratic Sufficiency

Graph-coloring constraints are pairwise. Principia Thm. 1.5.9 supplies the admissible quadratic interaction language. This removes any need for a primitive fifth-order interaction merely because five indexed obligations meet at a degree-five vertex.

### E2. Observer horizon

A distinction counts as terminally independent only if it remains discriminable above the observer floor. Apparent refinements below the horizon may remain as residue without increasing terminal quotient cardinality.

### E3. TTCS stochastic exploration

TTCS samples symbolic alternatives from a free-energy landscape. It may generate many latent chromatic states; cardinality of the latent state space is therefore intentionally larger than terminal chromatic cardinality.

### E4. TTPR contraction

TTPR must decrease residue while preserving external meaning/obligations. This is the natural home of browning-out: redundant value distinctions contract while indexed conflicts remain intact.

### E5. TTDC commitment boundary

TTDC commits only when continuation is insolvent or a stable candidate has formed. A fifth apparent class that cannot remain above the observer floor cannot be admitted merely by naming it.

### E6. TTIE residue re-expansion

If brown still hides unresolved conflict, TTIE re-expands it. Therefore `brown` cannot be used to mask an unsatisfied edge obligation.

Together these give a fail-closed cycle:

```text
candidate fifth distinction
  -> TTCS exploration
  -> TTPR refinement/amortization
  -> either existing terminal class
     or brown residue
  -> if brown still carries unresolved external conflict: TTIE re-expand
  -> TTDC commits only after all indexed obligations are satisfied
```

## 6. Degree-five local surface

For a minimal planar counterexample, the first nontrivial local obstruction is a degree-five vertex. Its five incident constraints remain separately indexed:

```text
O1, O2, O3, O4, O5.
```

The proof does **not** assert that the five neighbors form `K5`, nor that five distinct neighbor color values are present.

The local algebraic question is instead:

> Can the fifth indexed obligation force a fifth terminal value after all pairwise provenance-preserving refinements are exhausted?

`NoStableFifthClass` answers no. The obligation may remain distinct while its value requirement is amortized into a reuse/reorientation of the four terminal classes.

## 7. Brown is not a masking escape hatch

A browning step is admissible only if both conditions hold:

```text
(1) all external edge obligations remain represented;
(2) any unresolved obligation forces re-expansion before terminal commitment.
```

Thus this forbidden move is explicitly rejected:

```text
unsatisfied conflict -> brown -> pretend solved.
```

The admissible move is:

```text
multiple internal chromatic histories
  -> brown composite residue
  -> preserve their indexed obligations
  -> re-expand only where an obligation is still unresolved
  -> terminally commit using <= 4 stable classes.
```

## 8. Mechanical theorem surface for MeTTa

MeTTa should attempt to prove/refute the following predicates without access to the held-out Four Color conclusion:

```text
(ObligationPreserved $before $after)
(TerminalIdempotent $color)
(CompositeContracts $state)
(BrownIsComposite $state)
(UnresolvedBrownReexpands $state)
(FifthClassHasNovelInvariant $state)
(NoStableFifthClass $planar_conflict_object)
```

The decisive falsifier is constructive:

```text
exists planar conflict object P,
exists state x5,
  Terminal(x5)
  and IndependentOf(x5, q1,q2,q3,q4)
  and PreservesAllObligations(x5)
  and StableUnderSRMF(x5).
```

Finding such a witness refutes this proof route. Failure to find one is not itself proof; the algebraic closure rules must derive its impossibility.

## 9. Proof spine

The intended independent proof now has the form

```text
planar adjacency
  -> pairwise indexed obligations
  -> quadratic symbolic representation
  -> degree-five minimal obstruction
  -> four-stable / five-routes observer witness
  -> provenance-preserving browning-out algebra
  -> NoStableFifthClass
  -> admissible terminating refinement
  -> <= 4 terminal chromatic classes
  -> exact proper coloring
```

The `V4`/Tait route remains available as a downstream decode/check, but it is no longer the source of the claimed fourness. The proposed fourness arises from the symbolic color quotient itself.

## 10. Current status

This document sharpens the central theorem and supplies explicit algebraic laws and falsifiers. It does **not** yet certify `NoStableFifthClass` for all planar graphs.

The next mechanical step is to encode the browning laws in MeTTa and test whether the fifth-class predicate can survive the full SRMF cycle without either collapsing to an existing terminal class or remaining nonterminal brown residue.
