# SRMF, Fuzzy Calculus, Observer Floors, and the Four Color Theorem

> **Status: theorem-development note.** This document records a candidate correspondence and a concrete proof program. It does **not** claim that Fuzzy Calculus or SRMF has already proved the Four Color Theorem. The purpose is to make the strongest currently justified reduction explicit, identify the missing theorem, and give MeTTafy a leakage-safe way to test the convergence mechanically.

This note should be read beside [`four-color.md`](four-color.md) and [`auditability.md`](auditability.md).

## 1. Research question

Principia Symbolica (PS) contains the four SRMF operators

\[
\mathrm{TTDC}\to\mathrm{TTIE}\to\mathrm{TTCS}\to\mathrm{TTPR}\to\mathrm{TTDC},
\]

with an order-sensitive cyclic relation. In the current PS text, their mathematical roles are approximately:

- **TTDC** — bounded decision/collapse at an observer-relative boundary;
- **TTIE** — integration/expansion along feasible coherence trajectories;
- **TTCS** — coherent finite-temperature sampling over nearby candidate symbolic states;
- **TTPR** — recursive contraction/refinement toward a convergence-stable carrier.

The Four Color Theorem (4CT) states that every finite planar graph has a proper vertex coloring using at most four colors.

The research question is not whether both stories happen to contain the number four. The target is a structure-preserving theorem:

\[
\boxed{
\text{Fuzzy Calculus / SRMF observer dynamics}
\Longrightarrow
\text{an exact four-color witness for every admissible planar instance}
}
\]

with the derivation independent of the existing Four Color proof.

If such a theorem can be proved and independently checked, it would validate a nontrivial fragment of Fuzzy Calculus: observer-relative fuzzy exploration and refinement would have been shown to compile into a correct exact combinatorial witness. It would **not**, by itself, establish global soundness of all Fuzzy Calculus.

## 2. Observer floor: brown is a quotient, not necessarily a mixture

The first formulation of this note treated “brown” as an interior fuzzy mixture from which SRMF must escape. The stronger PS-native interpretation is observer-relative.

Let \(X\) be a latent structured state space and let an observer \(O\) have a local resolution floor \(\xi_O>0\). Define observational indistinguishability by

\[
x\sim_O y
\quad\Longleftrightarrow\quad
 d_O(x,y)\le \xi_O,
\]

or, more generally, by the observer-specific equivalence generated by that local tolerance. The observer receives only the quotient

\[
Q_O:X\to X/{\sim_O}.
\]

Distinct latent chromatic sectors can therefore project to the same coarse observed state:

\[
Q_O(c_1)=Q_O(c_2)=Q_O(c_3)=Q_O(c_4)=\bar c.
\]

The symbol \(\bar c\) is the mathematical role of **brown** in this note: not an ontological claim that the four sectors have physically mixed, but an observer-bounded image in which their distinctions are unresolved.

Now refine the observer. For \(O'\) with a lower floor

\[
\xi_{O'}<\xi_O,
\]

we require a refinement map

\[
r_{O'O}:X/{\sim_{O'}}\to X/{\sim_O}
\]

such that

\[
Q_O=r_{O'O}\circ Q_{O'}.
\]

Thus finer observation does not invent structure; it may split a coarse fiber into distinctions that were already latent:

\[
\{\bar c\}
\rightsquigarrow
\{c_1,c_2,c_3,c_4\}.
\]

In the idealized sharp-observer limit,

\[
\xi_O\to0,
\]

the quotient approaches the latent separation supported by the model.

### Claim boundary

This observer-floor picture is **not yet a proof of 4CT**. If we simply assume that every planar instance already contains four globally consistent latent color classes, the theorem has been smuggled into the premise.

The noncircular obligation is stronger:

> Starting from planarity, the specified FC/SRMF dynamics, and observer refinement — but **without assuming a four-coloring exists** — prove that every adjacency conflict becomes resolvable inside the four SRMF terminal channels and that no stable fifth independent terminal class is required.

That is the observer-floor form of the hard theorem.

## 3. Resolution filtration

Let \(\mathcal P_\xi\) denote the observable partition at resolution floor \(\xi\). Refinement should satisfy

\[
\xi'<\xi
\quad\Longrightarrow\quad
\mathcal P_{\xi'}\preceq\mathcal P_\xi,
\]

where \(\preceq\) means “is a refinement of.”

For an underlying planar interaction complex \(K\), let \(G_\xi(K)\) be the adjacency/conflict graph visible at resolution \(\xi\). The tempting statement

\[
\sup_\xi \chi(G_\xi(K))\le4
\]

is effectively a Four Color statement and therefore cannot be used as an assumption.

Instead the proof program must derive the bound from an SRMF refinement invariant. A useful theorem shape is:

### Conjecture — Chromatic observer-floor theorem

For every admissible finite planar interaction complex \(K\), there exists a bounded SRMF-guided refinement sequence

\[
O_0\prec O_1\prec\cdots\prec O_T
\]

such that:

1. each refinement preserves already certified nonconflicting distinctions;
2. every unresolved adjacency conflict either separates at a later floor or is shown equivalent to a previously represented terminal distinction;
3. no refinement step requires a fifth independent terminal channel; and
4. the terminal quotient admits an adjacency-preserving assignment into the four SRMF channels.

The corresponding lower bound is supplied by a planar 4-chromatic witness such as \(K_4\). Once the correspondence is established,

\[
4\le \text{universal terminal channel requirement}\le4.
\]

The upper bound is the substantive theorem; the lower bound is easy.

## 4. Imaginary traversal belongs below the current quotient

SRMF is richer than an exact coloring. It may traverse counterfactual or imaginary structure that is not available to the current observer.

A useful model is

\[
Z_t=X_t+iY_t,
\]

where \(X_t\) is the currently realizable/observable component and \(Y_t\) carries counterfactual traversal beneath the present observer quotient.

The crucial interpretation is:

> Imaginary traversal need not mean “temporarily accept an illegal coloring.” It can mean “explore distinctions that are still sub-threshold for the current observer.”

As the observer floor decreases, a previously imaginary or unresolved degree of freedom may become representable in the real terminal quotient.

A stochastic semantics remains possible:

\[
dZ_t=b_\theta(Z_t,K,O_t)\,dt+\sigma_\theta(Z_t,K,O_t)\,dW_t,
\]

which is compatible with the finite-temperature interpretation of TTCS. But no theorem below depends on this particular SDE. Brownian motion may be an implementation semantics for exploration; the observer-floor theorem is the structural target.

## 5. Amortization is the operational difference

The expensive operation is not necessarily solving each planar instance from scratch. It is discovering/compiling how observer refinement should expose useful distinctions.

Let an offline Fuzzy Calculus derivation compile

\[
\mathcal C_{\mathrm{FC}}
\longmapsto
\Pi_{\mathrm{SRMF}},
\]

where \(\Pi_{\mathrm{SRMF}}\) is a reusable refinement-and-traversal policy.

At application time,

\[
(K,O_0)
\xrightarrow{\Pi_{\mathrm{SRMF}}}
(O_1,Z_1)
\to\cdots\to
(O_T,Z_T)
\xrightarrow{\text{terminal projection}}
\text{exact witness}.
\]

For \(N\) instances, the average cost is

\[
\overline C_N
=
\frac{C_{\mathrm{compile}}}{N}
+
\frac1N\sum_{i=1}^N
\left(
C_{\mathrm{apply}}(K_i)
+C_{\mathrm{verify}}(K_i)
\right).
\]

The existence of a uniform four-coloring algorithm is not itself stronger than 4CT: finite exhaustive search already supplies a uniform algorithm once existence is guaranteed. The distinctive SRMF claim is about **amortized structure and cost**:

\[
\boxed{
\text{class-level fuzzy/imaginary discovery}
\to
\text{compiled observer-refinement policy}
\to
\text{cheap exact instance witness}
\to
\text{independent verification}.
}
\]

Correctness and amortization are separate claims. A valid coloring does not, by itself, demonstrate amortization.

## 6. Exact terminal boundary algebra

Once the observer has resolved an exact terminal witness, the four channels can be tested against the Klein four group

\[
\Gamma = \mathbb Z_2\times\mathbb Z_2
       = \{0,a,b,a+b\}.
\]

A candidate coordinatization of the SRMF cycle is

\[
\begin{aligned}
\mathrm{TTDC}&\mapsto 0,\\
\mathrm{TTIE}&\mapsto a,\\
\mathrm{TTCS}&\mapsto a+b,\\
\mathrm{TTPR}&\mapsto b.
\end{aligned}
\]

Then

\[
0\xrightarrow{a}a
\xrightarrow{b}a+b
\xrightarrow{a}b
\xrightarrow{b}0.
\]

The three nonzero elements are

\[
\Gamma\setminus\{0\}=\{a,b,a+b\}.
\]

This is mathematically relevant because a nowhere-zero \(\Gamma\)-flow on a cubic graph induces a Tait three-edge-coloring: if the three incident values at a cubic vertex are \(x,y,z\neq0\) and

\[
x+y+z=0,
\]

then they must be the three distinct nonzero elements. If \(x=y\), then \(z=x+y=0\), contradiction.

### Claim boundary

The mere existence of four SRMF operators does **not** prove that their algebra is \(\Gamma\). The coordinatization above is a proposed **terminal quotient algebra**. We must prove that the relevant SRMF terminal transitions respect the required group relations rather than merely relabeling four objects.

The temporal operator cycle and the terminal coloring algebra also need not be identical structures. The same four objects may carry a cyclic traversal relation internally and a Klein-group quotient relation at the exact boundary.

## 7. Classical bridge to Four Color

The classical graph-theoretic part is not proposed as new mathematics.

One standard route is:

1. augment a finite planar graph to a triangulation/maximal planar graph;
2. take the planar dual, obtaining a cubic bridgeless planar graph, aside from small trivial cases handled separately;
3. obtain a nowhere-zero 4-flow / \(\mathbb Z_2^2\)-flow on the cubic dual;
4. at each cubic vertex, the three nonzero flow values are distinct and therefore give a Tait three-edge-coloring;
5. transfer the Tait coloring back to a proper four-coloring of the primal graph;
6. restrict the coloring from the triangulation to the original graph.

Equivalently, planar coloring-flow duality can be used directly: a proper \(\Gamma\)-coloring is a nowhere-zero \(\Gamma\)-tension, and planar duality exchanges tensions with flows.

Therefore the exact downstream obligation can be localized:

\[
\boxed{
\textbf{SRMF Flow Obligation:}
\quad
\text{decode the resolved terminal state as a nowhere-zero }\mathbb Z_2^2\text{-flow.}
}
\]

The observer-floor theorem is upstream of this exact algebraic bridge.

## 8. A concrete fuzzy-to-exact flow lemma

Observer-floor dynamics explains **why structure may appear brown at coarse scale and separate under refinement**. The following independent lemma explains when an approximate terminal field is already close enough that exact modular conservation is forced.

Let

\[
\Gamma=\mathbb Z_2^2,
\qquad
\phi(\Gamma)=\{(0,0),(1,0),(0,1),(1,1)\}\subset\mathbb R^2,
\]

and let

\[
\Lambda=2\mathbb Z^2.
\]

Let \(H=(V,E)\) be an oriented graph with maximum degree \(\Delta\). Suppose the terminal observer sees a real fuzzy edge field

\[
x:E\to\mathbb R^2.
\]

Assume there is a unique decoded value \(g_e\in\Gamma\) for every edge such that

\[
\operatorname{dist}_\infty(x_e,\phi(g_e)+\Lambda)\le\varepsilon,
\qquad
\varepsilon<\tfrac12,
\]

and assume

\[
g_e\neq0\qquad\forall e\in E.
\]

For each vertex \(v\), let \(\sigma_{v,e}\in\{-1,+1\}\) be the orientation sign and define

\[
r_v=
\operatorname{dist}_\infty
\left(
\sum_{e\ni v}\sigma_{v,e}x_e,
\Lambda
\right).
\]

Assume

\[
r_v\le\delta\qquad\forall v
\]

and

\[
\boxed{\Delta\varepsilon+\delta<1.}
\]

### Lemma — fuzzy residue snaps to exact group conservation

Under these assumptions,

\[
\sum_{e\ni v}\sigma_{v,e}g_e=0
\qquad\text{in }\Gamma
\]

for every vertex \(v\). Therefore \(g:E\to\Gamma\setminus\{0\}\) is a nowhere-zero \(\Gamma\)-flow.

### Proof sketch

Let

\[
h_v=\sum_{e\ni v}\sigma_{v,e}g_e\in\Gamma.
\]

For some \(\lambda\in\Lambda\),

\[
\sum_{e\ni v}\sigma_{v,e}\phi(g_e)
=\phi(h_v)+\lambda.
\]

The fuzzy sum differs from this exact representative sum by at most

\[
\deg(v)\varepsilon\le\Delta\varepsilon
\]

in \(\ell_\infty\).

If \(h_v\neq0\), every representative of \(\phi(h_v)+\Lambda\) is at \(\ell_\infty\)-distance exactly \(1\) from \(\Lambda\). Hence the fuzzy sum must lie at distance at least

\[
1-\Delta\varepsilon
\]

from \(\Lambda\). But by assumption it lies within \(\delta\). The strict margin

\[
\Delta\varepsilon+\delta<1
\]

makes those statements incompatible. Thus \(h_v=0\).

For a cubic dual, \(\Delta=3\), so it is sufficient that

\[
\boxed{3\varepsilon+\delta<1.}
\]

This is a **decoding theorem**, not the global existence theorem. It says that once refinement exposes a sufficiently separated, sufficiently conservative terminal field, exact group structure follows.

## 9. The hard theorem has changed shape, not disappeared

The previous version called the unresolved step a “global reachability” problem: prove that SRMF can always drive a fuzzy state into the exact-decoding margin.

Observer-floor dynamics refines that obligation:

### Conjecture — SRMF observer-refinement reachability

For every admissible finite planar interaction complex \(K\) and every admissible initial observer \(O_0\), the compiled SRMF policy admits a bounded real/imaginary refinement trajectory

\[
(K,O_0,Z_0)
\to\cdots\to
(K,O_T,Z_T)
\]

such that:

1. all adjacency distinctions required by the planar instance are resolved at \(O_T\);
2. the resolved terminal representation uses no more than the four SRMF channels;
3. corresponding dual edges decode to nonzero elements of \(\mathbb Z_2^2\);
4. the terminal fuzzy field satisfies \(\Delta\varepsilon+\delta<1\); and
5. the trajectory terminates under an explicit resource bound.

If this theorem is proved without importing 4CT or an equivalent existence theorem, the fuzzy-to-exact lemma yields a nowhere-zero 4-flow and the classical transfer yields a proper four-coloring.

The noncircular content is exactly the statement that **planarity plus SRMF observer-refinement dynamics prevents a persistent fifth-class obstruction**.

## 10. Candidate proof invariant: unresolved-conflict descent

To prove the observer-refinement theorem, we need a quantity that cannot decrease forever without resolving the relevant adjacency conflicts.

Let \(U_t\subseteq E(G)\) be the set of adjacencies that remain indistinguishable or conflicting at observer floor \(\xi_t\). Define a process functional

\[
F_t
=
\alpha\,|U_t|
+\beta\,R_t
+\gamma\,C_t,
\]

where:

- \(|U_t|\) counts unresolved adjacency obligations;
- \(R_t\) is a conservation/consistency residual;
- \(C_t\) is a resource or refinement cost term.

A useful theorem would show that whenever \(U_t\neq\varnothing\), at least one SRMF move yields either

\[
F_{t+1}<F_t
\]

or a certified structural reduction to a strictly smaller equivalent planar instance.

This is intentionally only a **candidate invariant**. The earlier PS convergence theorem to a local minimum is not enough. For Four Color we would need to prove one of the following stronger statements:

- no local minimum with unresolved conflict exists on admissible planar instances;
- every nonzero unresolved residue exposes a permitted refinement direction;
- or every apparent fixed point with unresolved conflict reduces to a smaller counterexample, contradicting minimality.

That last option is especially interesting because it would connect observer-floor dynamics to the minimal-counterexample structure that MeTTafy is independently extracting from the Rocq proof — but this comparison must happen only **after** the SRMF derivation is frozen, to avoid leakage.

## 11. Proposed SRMF amortized four-color theorem

A useful final theorem shape is:

### Theorem target — SRMF amortized observer-floor four-color soundness

There exists a policy \(\Pi_{\mathrm{SRMF}}\), derivable from a specified Fuzzy Calculus/SRMF fragment without invoking 4CT or an equivalent theorem, such that for every admissible finite planar graph \(G\):

1. \(\Pi_{\mathrm{SRMF}}(G,O_0)\) terminates under an explicit resource bound;
2. coarse observer states may quotient multiple latent distinctions into one apparent class;
3. real/imaginary refinement resolves every adjacency obligation without requiring a fifth independent terminal channel;
4. the terminal state satisfies the fuzzy-to-exact flow lemma;
5. decoding yields a nowhere-zero \(\mathbb Z_2^2\)-flow on the selected planar dual;
6. classical transfer yields a proper four-coloring \(c_G\); and
7. an independent checker verifies

\[
\operatorname{Proper4Coloring}(G,c_G).
\]

A separate complexity theorem or benchmark must establish any claimed amortization benefit.

## 13. Mechanical witness program

The conjecture should advance only by green mechanical witnesses.

### W1 — observer-floor quotient laws

Formalize a finite observer model with:

- resolution floors;
- quotient maps;
- refinement maps;
- the commutation law \(Q_O=r_{O'O}\circ Q_{O'}\);
- examples where several latent states collapse to one coarse state and split under refinement.

This witness must **not** assume a globally valid four-coloring.

### W2 — quartet / Klein terminal algebra

Formalize the candidate terminal quotient and prove the relevant cycle/Klein identities. Explicitly separate temporal-cycle properties from terminal group properties.

### W3 — fuzzy-to-exact flow lemma

Formalize the torus decoding lemma above in Lean or Rocq.

### W4 — cubic/Tait transfer

For a cubic graph, prove that a nowhere-zero \(\mathbb Z_2^2\)-flow gives exactly the three distinct nonzero incident values and therefore a Tait coloring. Connect that theorem to an independently checked planar dual transfer.

### W5 — observer-refinement finite witnesses

On planar test instances, emit the entire refinement trace:

- observer floors \(\xi_t\);
- quotient classes at each floor;
- unresolved adjacency set \(U_t\);
- real and imaginary traversal metadata;
- terminal fuzzy edge states;
- decoded group labels;
- \(\varepsilon\);
- vertex residuals;
- \(\delta\);
- the margin \(\Delta\varepsilon+\delta\);
- the exact decoded flow; and
- the final four-coloring.

The verifier should reject the witness if the stated observer/refinement invariants fail even when the final coloring happens to be valid.

### W6 — fifth-class obstruction search

Mechanically search bounded planar instances for a terminal state in which the proposed SRMF dynamics becomes stuck while an unresolved conflict still demands a fifth independent channel.

This is a falsification witness. A counterexample is valuable.

### W7 — amortization benchmark

Measure compile cost once, then application and verification costs over a held-out family of planar instances. Compare against explicit baselines. Do not infer amortization from correctness alone.

### W8 — blind strategy correspondence

After both proof paths are frozen, compare their MeTTafy Strategy IRs post hoc. Record agreements, disagreements, abstentions, and possible label leakage.

## 14. Proof obligations checklist

The following must become explicit before claiming that Fuzzy Calculus proves Four Color:

- [ ] **P1 — planar representation fidelity:** every target planar instance maps to an admissible PS/SRMF interaction complex without changing the coloring problem;
- [ ] **P2 — observer quotient laws:** coarse observation and refinement are well-defined and commute as specified;
- [ ] **P3 — noncircular chromatic refinement:** planarity + FC/SRMF dynamics, not a hidden coloring assumption, force all adjacency obligations to resolve within four terminal channels;
- [ ] **P4 — terminal quotient algebra:** the four exact terminal sectors carry the required \(\mathbb Z_2^2\) structure rather than merely four names;
- [ ] **P5 — nonzero separation:** corresponding dual edges cannot decode to zero difference;
- [ ] **P6 — fuzzy-to-exact conservation:** mechanically prove the terminal margin lemma;
- [ ] **P7 — bounded execution:** state an ex ante termination/resource bound for the compiled refinement policy;
- [ ] **P8 — classical transfer:** independently formalize or import with explicit trust boundary the flow/Tait-to-four-color bridge;
- [ ] **P9 — exact verification:** generated colorings are checked by a conventional checker/proof assistant;
- [ ] **P10 — dependency audit:** the FC/SRMF derivation contains no hidden use of 4CT or an equivalent existence theorem;
- [ ] **P11 — amortization:** separately prove or benchmark the claimed reusable cost advantage.

The critical unknown is now **P3**, with P7 close behind it. The fuzzy-to-exact flow lemma is downstream machinery; observer-floor refinement is the actual candidate source of the Four Color upper bound.

## 15. What success would validate

If P1–P10 are mechanically green, then we can reasonably claim:

> A specified fragment of Fuzzy Calculus/SRMF independently constructs exact witnesses for the Four Color Theorem through observer-floor refinement and a verified fuzzy-to-discrete correspondence.

That would validate at least:

- the expressive adequacy of the tested FC/SRMF fragment for this domain;
- the soundness of the particular observer-refinement and fuzzy-to-exact derivation;
- the claim that observer-relative unresolved structure can refine into conventional exact proof objects;
- the correspondence between the PS frame/operator representation and a classical graph-theoretic invariant.

It would **not** yet establish:

- soundness of every Fuzzy Calculus rule;
- uniqueness of SRMF as the only possible four-color process;
- that Brownian or imaginary traversal is mathematically necessary rather than operationally useful;
- superior asymptotic complexity; or
- that the existing PS local convergence theorem already implies P3.

A stronger validation would require a general semantics-preservation theorem translating a substantial FC fragment into a conventional proof assistant.
